# Cadence - Presentation Slide Generation Prompt

## Project Information
Generate a 20-slide professional presentation for Cadence, a research-backed voice screening tool for Parkinson's disease. The slides will be used as a slideshow overlay in specific sections of a 3-minute video pitch.

---

## Brand Guidelines & Color Palette

**Primary Brand Colors:**
- **Brand Purple:** #6c5ce7 (primary brand color, use for headings, key highlights, CTAs)
- **Brand Purple Light:** #8b7ff0 (secondary accent, use for gradients and highlights)
- **Brand Soft:** #efedfd (light purple background for callout boxes)

**Accent Colors:**
- **Teal:** #17b8a6 (positive indicators, success states)
- **Teal Soft:** #e2f7f4 (teal backgrounds)
- **Coral:** #f2775f (warnings, attention points)
- **Coral Soft:** #fdeae5 (coral backgrounds)

**Neutrals:**
- **Ink (Dark):** #3b3660 (body text, primary content)
- **Ink Soft:** #847ea6 (secondary text, captions)
- **Line:** #ece9fb (dividers, borders)
- **Card/White:** #ffffff (backgrounds)

**Background Gradient:**
- Use a subtle gradient: `linear-gradient(170deg, #faf9ff 0%, #f6f5ff 55%, #f2fbfa 100%)`
- This creates a gentle purple-to-teal fade

**Typography:**
- **Headings:** Baloo 2 (bold, rounded, friendly) - font-weight: 700-800
- **Body Text:** Quicksand (clean, modern, readable) - font-weight: 400-600
- Keep text minimal and large (minimum 24pt for body, 48pt+ for headings)

**Design Style:**
- Clean, modern, minimalist
- Rounded corners on all elements (16-20px border-radius)
- Soft shadows: `0 16px 36px -18px rgba(108,92,231,0.38)`
- Ample white space
- Left-align text for readability, center for impact statements
- Use icons where appropriate (medical cross, microphone, chart, brain, checkmark)

## Technical Specifications for AI Generation

**Aspect Ratio:** 16:9 (1920x1080px or 1280x720px)

**Export Format:** 
- PNG (high quality, transparent backgrounds where appropriate)
- Or PDF (vector, one slide per page)

**Animation Suggestions (if using in video editing):**
- Fade in/out transitions (0.3-0.5 seconds)
- Text: subtle slide-up or fade-in for bullet points
- Numbers/stats: count-up animation for impact
- Slide 13 (Shuffled Control): highlight the 84→38 drop with color change animation

**Accessibility:**
- Ensure text has minimum 4.5:1 contrast ratio with backgrounds
- Use WCAG AA compliant color combinations
- Keep font sizes large (never below 18pt for body text)

**Consistency Rules:**
- All headings use Baloo 2
- All body text uses Quicksand
- Maintain 40-60px margins on all sides
- Card/box padding: minimum 20-24px
- Icon size: 48-64px for large icons, 24-32px for small
- Consistent shadow on all elevated elements
